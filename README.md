# dice-roll

A small standup leader picker. Enter names, save them as a team, switch
between saved teams, then roll the dice to pick who leads today's standup.

## Usage

Open `index.html` in a browser, or serve the folder statically, e.g.:

```
npx serve .
```

Teams and their members are saved in the browser's local storage, so they
persist between visits on the same device/browser.
